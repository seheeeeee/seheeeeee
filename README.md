### 👩‍💻 소개

- 반응형·적응형 웹, 하이브리드 웹앱, PG 결제 브릿지 개발 경험이 있습니다.
- **미스고**는 경·공매 부동산 정보 플랫폼으로, 하이브리드 웹앱 내 지도 페이지를 개발했습니다.  
  네이버 지도 API와 공공 API를 연동하여 마커, 필지 라인, 카드, 상세페이지 등 지도 위에 데이터를 시각화하는 작업을 담당했습니다.
- **꿀스테이**는 숙박 예약 애플리케이션입니다.  
  앱 운영을 위한 내부 CMS와 제휴점주용 파트너 센터(PMS)를 개발했으며,  
  이용자 앱과 PG 결제 모듈을 연결하는 웹 브릿지에 신규 PG사를 연동하고 오류를 개선한 경험이 있습니다.
- React 및 Next.js를 메인 스킬로 사용하며, Vue.js는 개인 프로젝트를 통해 학습했습니다.
- Cypress를 활용해 E2E 테스트를 도입하고, 주요 기능에 대한 안정성을 확보하고 있습니다.
- 프론트엔드 특화 에러 모니터링 시스템의 필요성을 느껴 **Sentry**를 직접 도입하고 운영 중인 프로젝트에 적용했습니다.
